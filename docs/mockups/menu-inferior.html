Menu inferior no celular: 3 estilos

Os três quadros usam as telas e os nomes reais do OrchestraPlanner. A barra aparece só no celular (tela com menos de 768 px). No computador entra o menu lateral fixo, com a mesma lista de itens. Toque nos itens para ver o estado ativo; "Mais" (e o "+") abre a folha com o resto.

As metas e o saldo dentro dos quadros são dados de exemplo. As cores de Corpo (terracota), Alma (azul-petróleo) e Espírito (dourado) aparecem só onde querem dizer a dimensão. Se o menu usasse terracota para o item ativo, "estou aqui" ficaria parecendo "Corpo".

Trocar de estilo depois

Pílula e Traço estão os dois no código. Trocar um pelo outro é mudar uma linha (BOTTOM_NAV_STYLE em src/app/dashboard/nav-items.ts), uns 5 minutos com o CI. O Botão central exige criar uma janela de "criação rápida" que o app ainda não tem: são ~2–3 h a mais, e Metas sai da barra.
