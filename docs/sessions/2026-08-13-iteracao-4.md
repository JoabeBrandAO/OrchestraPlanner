## 2. Decisões / aprendizados

- **Idempotência de escrita concorrente é do banco, não de um `if`.** O seed lia "já existe?"
  e só então inseria — *check-then-act*. Em READ COMMITTED a inserção não-commitada de uma
  transação é invisível para a outra, e `ensureUserRecord()` roda em toda página autenticada.
  A Iteração 3 acrescentou uma terceira página chamando o seed, o que tornou a corrida
  provável o bastante para aparecer. Correção: índice único + `on conflict do nothing`.
- **Apagar duplicata não pode custar dado.** A migration remapeia metas e avaliações para a
  área sobrevivente **antes** de apagar as cópias; sem isso o `ON DELETE SET NULL` de
  `goals.life_area_id` desligaria metas em silêncio.
- **O erro do driver não vaza para a tela.** O `23505` vira uma frase do domínio — e a
  detecção percorre a cadeia de `cause`, porque o Drizzle embrulha o erro do driver e o
  `code` do Postgres **não** está no topo (descoberto por teste vermelho).
- **Comparação de data em query usa os helpers do Drizzle** (`gt`/`gte`/`lt`), nunca o
  template `sql` cru: ele não mapeia o tipo e o driver recebe um `Date` que não serializa
  (5 testes vermelhos até trocar).
- **Recorrência guardada como regra**, não como linhas materializadas: "toda segunda" é uma
  linha, não 520. Materializar exigiria escolher até quando gerar e transformaria editar a
  série numa caçada a N linhas.
- **O mês sem o dia da série é pulado**, não grudado no dia 28/30 — "todo dia 31" não pode
  virar "todo fim de mês" (RFC 5545, BYMONTHDAY). Idem 29/02, que só ocorre em bissexto.
- **Migration automática não pode morar no build da Vercel:** o build roda em preview de
  cada PR, então bastaria um PR para migrar produção antes da revisão.
- **Aritmética de recorrência em UTC** é exata para o Brasil (sem horário de verão desde
  2019); o módulo marca o que muda quando houver múltiplos fusos.
